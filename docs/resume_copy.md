# 简历项目表述

## 推荐版本

**AI Native交通数据质量审查与建模助手｜个人项目**

- 将数据画像、重复值清理、缺失值处理、时间特征构造、数据验证及基线建模封装为可复用Python工具，搭建自然语言需求到数据报告的本地工作流。
- 设计目标泄漏诊断模块，通过字段语义与单变量阈值搜索识别`speed_kmh <= 34.5`可100%复现拥堵标签，并自动排除速度、拥堵等级和记录编号等高风险字段。
- 实现规则规划器与Ollama本地模型双模式，将用户需求转换为白名单JSON计划；通过人工确认、安全合并、验证失败中止及规则回退限制大模型误操作。
- 设计泄漏字段与数据划分对照实验：同一决策树包含泄漏字段时Accuracy为100%，排除风险字段后随机划分为83.89%、时间划分为87.78%；按训练/验证/测试时间切分选择逻辑回归，最终测试集Recall为98.55%。
- 使用Streamlit展示数据质量评分、风险证据、Agent执行轨迹及模型指标，导出清洗数据、JSON日志、可视化图表和HTML分析报告。

## 一页简历压缩版

- 将交通数据清洗、特征工程、泄漏诊断、质量验证与建模封装为Agent白名单工具，构建本地自然语言数据处理工作流。
- 识别速度阈值可100%复现拥堵标签的目标泄漏，并通过泄漏前后、随机/时间划分对照说明虚高指标风险；严格时间切分后的最终测试集Recall为98.55%。
- 实现规则与Ollama双规划模式、人工确认、失败回退、执行日志及Streamlit可视化，支持导出数据质量和模型风险报告。
