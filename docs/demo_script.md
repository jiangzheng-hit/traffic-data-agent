# 三分钟演示脚本

## 第一幕 数据不是拿来就能训练

打开项目后展示顶部指标：726行、22字段、6条重复记录、30个缺失单元格。进入数据概览，展示缺失值和交通关系图。

讲解：系统不会直接训练模型，而是先判断这份数据能不能安全用于当前目标。

## 第二幕 发现100%的陷阱

选择`is_congested`并进入风险诊断。重点展示：

`speed_kmh <= 34.5`可100%复现目标标签。

讲解：如果把速度作为输入，模型学到的不是未来拥堵规律，而是标签生成规则。

## 第三幕 Agent计划和安全约束

输入：

`清理数据，排除目标泄漏，构造高峰时段特征，并用时间顺序划分建立拥堵基线。`

生成计划后展示工具、原因、参数和确认要求。强调大模型只能影响结构化计划，不能执行任意代码，也不能移除安全字段。

## 第四幕 结果与证据

确认执行后展示：

- 清洗后720行，重复与缺失均为0。
- 带泄漏字段的决策树为100%。
- 排除泄漏与冗余字段后随机划分为83.89%。
- 排除泄漏后时间划分为87.78%。
- 正式流程在验证集比较三类模型后选择逻辑回归，最终时间测试集Accuracy为93.75%、Recall为98.55%。

## 结束语

这个项目的目标不是让AI替用户把分数做高，而是让AI帮助用户发现数据风险，并通过受约束的工具链得到可复现、可解释的结果。
